# Sources and evidence

The eighteen principles below are paraphrased teaching takeaways. The examples are original applications, not book-page reproductions or quotations. A principle may have many valid implementations; the contrast state is a controlled study, not a claim that every alternative is wrong.

| Examples | Book | Reference coverage |
| --- | --- | --- |
| T1 hierarchy, T2 measure, T3 repeated roles | Ellen Lupton, *Thinking with Type* | [Publisher overview](https://www.chroniclebooks.com/products/thinking-with-type-1) supports typography, hierarchy, spacing, and grid topics. |
| G1 alignment, G2 proportions, G3 intervals | Josef Müller-Brockmann, *Grid Systems in Graphic Design* | [Publisher overview](https://niggli.ch/en/products/rastersysteme-fur-die-visuelle-gestaltung) describes the grid method; no full-text page verification claimed. |
| C1 simultaneous contrast, C2 color in context, C3 isolated variation | Josef Albers, *Interaction of Color* | [Albers Foundation teaching account](https://www.albersfoundation.org/alberses/teaching/interaction-of-color) explains contextual perception and observational exercises. Constant HSL lightness does not mean equal perceived brightness. |
| R1 de-emphasis, R2 spacing scale, R3 proximity | Adam Wathan and Steve Schoger, *Refactoring UI* | [Official contents and sample tactic](https://refactoringui.com/) cover de-emphasis, spacing systems, and avoiding ambiguous spacing. |
| W1 voice, W2 pairing, W3 adaptation | Jason Santa Maria, *On Web Typography* | [Publisher overview and contents](https://abookapart.com/products/on-web-typography.html), plus [author's book excerpt](https://alistapart.com/article/how-we-read/). Typeface tone is contextual and subjective. |
| B1 body-text conditions | Matthew Butterick, *Practical Typography* | [Typography in ten minutes](https://practicaltypography.com/typography-in-ten-minutes.html): the example isolates line spacing. |
| B2 selective emphasis | Same | [Bold or italic](https://practicaltypography.com/bold-or-italic.html). |
| B3 punctuation | Same | [Straight and curly quotes](https://practicaltypography.com/straight-and-curly-quotes.html), [hyphens and dashes](https://practicaltypography.com/hyphens-and-dashes.html). |
