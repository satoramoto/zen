# Awesome Design

React + TypeScript (TSX), Vite, Vitest, Storybook. This is a visual learning library: six books, eighteen principle demonstrations. Keep examples native React components shared by the app and their stories; do not inject HTML documents or embed the previous inline brief.

## Preview

Use only the unified launcher:

```sh
PREVIEW_LABEL="Awesome Design" PREVIEW_PORT=4191 STORYBOOK_PORT=6021 npm run dev
```

It owns app and Storybook startup and shutdown. If one child fails, stop/restart the complete assignment-owned launcher group; do not start a replacement child independently. Never stop unrelated processes or use occupied ports. Allocate unique port pairs to isolated worktrees.

## Quality

- Preserve all eighteen stable example IDs and their source references.
- Keep comparisons honest: state which variables change and what stays fixed.
- Book summaries are paraphrases. Publisher descriptions support topic alignment, not exact full-text fidelity.
- Storybook Controls must affect the specimen. Canvas interactions must work in both the app and Storybook.
- Validate at narrow widths. Sliders must change the actual drawing, not just the displayed number.
- Do not replace browser evidence with builds or unit-test results. Review conceptual fidelity separately from interaction and layout checks.
- Use meaningful tests for state and fixed-value invariants.

Run `npm run typecheck`, `npm test`, `npm run build`, and `npm run build:storybook` before a tested handoff.

## Ownership

Follow the user's native-agent isolation/integration policy. Keep main separate until landing is authorized. Do not push or create a remote/PR without task authorization. Preserve clean, recoverable ownership records before worktree cleanup.
